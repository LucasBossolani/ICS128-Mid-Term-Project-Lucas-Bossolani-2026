On this project folder you'll find: index.html, style.css, script.js, baseUsers.js and a folder called 'Images' that leads to all the images and gifs that I've used on my page. I've been creating repositories for all my projects and I did for this one as well. If you see a .git folder that's is the reason.

On my page, you will be able to: Login as one of the users provided by me, observe an array of objects formatted using CSS and Bootstrap, and, If the selected user has admin permissions, delete other users from the array. 

The set up for this is very straight up: Run index.html and you're done. You'll find all user information on the file baseUsers.js.

For this project, I've choose a Street Fighter 2 theme. It's a game that I love and it motivated me to work on this project. I've used arcade style fonts and tried to replicate colors from the arcade machines as well as the colors from the actual game. Each user represents a character from the game. Unfortunately, the original game has 8 playable characters so I had to user other characters from other SF games. I've used game sprites for my icons, background and gif.
